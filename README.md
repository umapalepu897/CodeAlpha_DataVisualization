# CodeAlpha Data Visualization

## Project Overview

This project focuses on visualizing a books dataset using Python, Pandas, and Matplotlib.

The goal is to transform raw book data into clear visualizations and identify useful patterns and insights.

## Technologies Used

- Python
- Pandas
- Matplotlib

## Dataset

The dataset contains information about books, including:

- Book Title
- Price
- Availability
- Rating

## Visualizations

The project includes the following visualizations:

1. **Book Rating Distribution**
   - Shows the number of books for each rating.

2. **Book Price Distribution**
   - Shows how book prices are distributed.

3. **Top 10 Most Expensive Books**
   - Displays the 10 books with the highest prices.

4. **Price Distribution by Rating**
   - Compares book prices across different ratings.

## Key Insights

- Total books analyzed: **20**
- Average book price: **£38.05**
- Minimum book price: **£13.99**
- Maximum book price: **£57.25**
- Most common rating: **One**
- All books in the dataset are listed as **In stock**.

## Project Files

- `visualization.py` – Python visualization code
- `books_dataset.csv` – Dataset
- `rating_distribution.png` – Rating distribution chart
- `price_distribution.png` – Price distribution chart
- `top_10_expensive_books.png` – Top 10 expensive books chart

## Conclusion

The visualizations provide a clear understanding of book prices, ratings, and other patterns in the dataset.
